## 🚀 How to Deploy in Google Apps Script

1. Open the Google Spreadsheet connected to your TECHBYTE SUMMIT 26.
2. Go to **Extensions** > **Apps Script**.
3. Select all code in `Code.gs` and replace it with [`google-apps-script/Code.gs`](file:///c:/Users/Admin/Downloads/Team_registration/google-apps-script/Code.gs).
4. Click **Deploy** > **Manage deployments**.
5. Click the edit icon (pencil) on your active Web App deployment.
6. Under **Version**, select **New version** (e.g. Version 2 or 3).
7. Click **Deploy**.
8. Ensure the endpoint URL ending in `/exec` matches:
   `https://script.google.com/macros/s/AKfycbyIIyg2C5VOVYKXagutyVlLsMv4xxZ97tiFUbm7R3zzI1KQXpEXmmjCJDacG36YitIR/exec`
